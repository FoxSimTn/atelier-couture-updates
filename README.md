# ERP Atelier Couture

Ce dépôt distribue les installateurs Windows et les métadonnées signées des mises à jour de l’ERP Atelier Couture.

Les fichiers sont disponibles dans [Releases](https://github.com/FoxSimTn/atelier-couture-updates/releases). Le code source du projet et les données des ateliers ne sont pas publiés dans ce dépôt.

Dans une version Windows compatible GitHub, ouvrez Administration → Paramètres → Mises à jour de l’ERP et utilisez cette adresse :

```text
https://github.com/FoxSimTn/atelier-couture-updates/
```

La première version compatible doit être installée manuellement si votre version ne prend en charge que les mises à jour sur le réseau interne.

L’application vérifie la signature de la publication et l’empreinte de l’installateur avant de proposer son installation.
